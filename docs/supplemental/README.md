# GeoFormerX Supplemental Material

This directory contains the supplemental material accompanying the manuscript:

**GeoFormerX: Parameter-efficient multimodal foundation-model adaptation for structured pavement condition information extraction**

## Contents

- **Table S1:** Exact reproducibility identifiers, split definitions, source revisions, checkpoint digests, and full-precision preprocessing constants.
- **Figures S1-S6:** Deterministically selected qualitative test examples showing grayscale intensity, the range-coded raster, the reference mask, and predictions from GeoFormerX, FrozenSAM, and CMX.
